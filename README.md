# Macro Toolkit

Frameworks I built for the Amsterdam Investment Club macro desk (Sep–Nov 2026) to aid with macro analysis.

Sector Scorecard: scores GICS sectors 1–5 across fundamentals, valuation, flows, technicals and sector-specific macro drivers to rank sector positioning.
Macro Overlay Tracker: tracks growth, inflation, labour, rates_policy, consumer,housing and credit indicators to determine the macro phase.

Status: framework complete; data partially populated, as of Oct 2026.
